# 远程使用指南：在公司连家里的 Studio

适用场景：Mac Studio 在家常开，人在公司，**Android 手机和笔记本都要从外网访问**
思港 Web 与 Studio 命令行。方案：**组网**（加密虚拟内网，免费，免公网 IP、
免路由器端口转发、免域名）。蒲公英、ZeroTier、WireGuard 等方案任选——
思港不挑组网方案，`port serve` 启动时会自动识别组网网卡，横幅里分别给出
**组网地址**和**局域网地址**。

```
公司笔记本 ─┐
Vs3 手机 ──┼── 组网虚拟内网（任何网络下如同同一局域网）
家里 Studio ┘
   ├─ 手机 Chrome  → http://<组网地址>:8787   思港 Web/PWA
   └─ 笔记本 ssh   → ssh jmzx@<组网地址>       完整命令行（含 port）
```

> 组网方案普遍支持设备间直连优先（NAT 打洞），不经过任何服务器；
> 打洞失败时才走加密中继。Web 和 SSH 是同一个通道，**不需要单独做内网穿透**。

---

## 一、Studio 端（一次性，在家操作）

1. 安装一个你用着顺手的组网客户端并登录，例如：
   - **蒲公英**（国内网络友好，手机端叫「蒲公英VPN」）；
   - ZeroTier、自建 WireGuard 等同理。

   手机和笔记本都要加入**同一个组网网络/账号**。记下 Studio 的组网地址
   （客户端里能看到；蒲公英通常是 172.x.x.x）。
2. 开启「远程登录」（系统 SSH）。二选一：
   - 系统设置 → 通用 → 共享 → 远程登录 → 打开；或
   - 终端执行：`sudo systemsetup -setremotelogin on`。
3. 确认思港服务在跑（监听 0.0.0.0 才能被组网访问）：
   ```bash
   port serve --host 0.0.0.0 --port 8787 --auth
   ```
   启动横幅会直接打印本机的**组网地址**和**局域网地址**。
   外网访问建议带上 `--auth` 上锁，手机扫码配对即可（见第五节）。

## 二、Vs3 手机端（一次性）

1. 安装同一个组网方案的手机客户端：
   - 蒲公英：应用市场搜「蒲公英VPN」，登录同一账号；
   - 其他组网方案装各自的 Android 客户端，登录同一账号/网络。
2. 打开客户端，用**同一个账号**登录并连接。
3. Chrome 访问横幅上的**组网地址**，如 `http://172.16.0.2:8787`：
   - 未上锁：直接打开，菜单「添加到主屏幕」即得到思港图标；
   - 已上锁：在电脑上另开终端运行 `port pair`，扫描终端里的二维码完成配对
     （10 分钟一次性配对码；每台设备独立授权，`port devices` 可吊销）。
4. 出门后保持组网连接即可，用法和在家 WiFi 完全一样。

若想在手机上直接敲命令行：装 **Termius**（SSH 客户端），host 填组网地址，
账号 `jmzx`，密钥见第三节。

## 三、笔记本端（一次性）

1. 安装同一个组网客户端，同一账号登录并连接；
2. 免密登录（推荐密钥；macOS/Linux，Windows 用 PowerShell 同理）：
   ```bash
   ssh-keygen -t ed25519                      # 已有密钥可跳过
   ssh-copy-id jmzx@<studio-组网地址>          # 输一次 Mac 登录密码
   ssh jmzx@<studio-组网地址>                  # 以后免密
   ```
3. `~/.ssh/config` 起个别名，以后 `ssh studio` 即可：
   ```
   Host studio
       HostName <studio-组网地址>
       User jmzx
       ServerAliveInterval 30
   ```
   组网客户端若支持固定域名/机器名，HostName 也可以直接写域名，IP 变化不用改配置。
4. 登录后即可远程使用：
   ```bash
   ssh studio
   port list
   port claim T0003
   tail -f ~/MindPort/.port/serve.log
   ```

## 四、验收清单

- [ ] 公司网络下，手机组网客户端显示已连接，浏览器打开思港页面 200
- [ ] 手机记下一条念头，Studio 上 `port list` 的草稿区立即出现新 T 编号
- [ ] 笔记本 `ssh studio` 登录成功，`port list` 正常
- [ ] Studio 重启后：先启动组网客户端（设为开机自启），再启动 `port serve`

## 五、安全说明

- 组网是**私有网络**：只有你账号下、显式登录的设备能看到 Studio，
  公网扫描不到 8787 与 22 端口；
- SSH 登录仍受 macOS 账户密码/密钥保护；建议关闭密码登录、只留密钥
  （`/etc/ssh/sshd_config` 中 `PasswordAuthentication no`，熟了再改）；
- 默认不上锁时，思港 Web **没有应用层鉴权**——安全性完全依赖网络边界
  （家庭 LAN + 你的组网）。不要把 8787 端口通过路由器转发到公网。
- 跨网络或不完全信任的网络里，用 `--auth` 上锁：电脑运行 `port pair`
  显示二维码，手机扫码完成该设备配对；`port devices` 查看与吊销设备，
  兜底用 `port web-token` 的访问密钥在 `/login` 粘贴。

## 六、组网方案不通时的备选

国内少数网络对 UDP 不友好会导致直连失败、中继偏慢，可换方案：

1. **蒲公英**：国内服务器中继，对国内网络兼容性好，免费版有设备数/带宽上限；
2. **ZeroTier**：同类虚拟内网产品；
3. **自建 WireGuard**：自己完全掌控，需要一台有公网 IP 的服务器做握手节点；
4. **frp / rathole + 一台云服务器**：自建 TCP 隧道，SSH 与 HTTP 都能转发，
   最可控但需要 VPS。

连通有问题时，先在组网客户端里确认 Studio 是直连还是中继、组网 IP 是否
与 `port serve` 横幅上的"组网地址"一致，把结果带来按情况选方案。
